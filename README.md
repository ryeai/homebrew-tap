# Homebrew Tap for Rye

Official [Homebrew](https://brew.sh) tap for [Rye](https://rye.ai) — AI agent proxy and audit CLI.

## Install

```bash
brew install ryeai/tap/rye
```

## Start the daemon

```bash
brew services start rye
```

## Usage

```bash
rye auth login
rye up
```

## Updating

```bash
brew upgrade ryeai/tap/rye
```
